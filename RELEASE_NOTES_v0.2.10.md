# UsageDock v0.2.10

UsageDock `v0.2.10` is a major feature release introducing Google's Antigravity (Gemini/AI IDE) quota tracking and a highly compacted tray layout.

## Highlights

- **Google Antigravity Support**: Fully integrates Antigravity quota tracking. Discovers running local language servers and parses Gemini / Claude usage quotas without credentials, or falls back to Cloud Code API sync.
- **Compacted Layout**: Re-engineered header and footer into 1-row compact compositions, reclaiming ~102px (over 20% of vertical tray space) for more provider cards.
- **Settings Panel**: Moved auto-refresh and check-for-updates controls into a new slide-down menu accessed via a gear icon.
- **UI Polishes**: Narrowed status pill, tightened logo-to-title gap, and removed duplicate reset timers.

## Installation

- Windows installer: `UsageDock_0.2.10_x64-setup.exe`
- Platform: Windows x64
- Install mode: per-user, no administrator privileges required
